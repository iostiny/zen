# iostiny / zen

中文读书笔记 · 思想卡片 · 长期思考。

部署在 `https://zen.iottiny.top/`（GitHub Pages，main branch / root）。

跟 [`iostiny/doc`](https://github.com/iostiny/doc) 是姊妹站：

| | 内容 | 域名 |
|---|---|---|
| `doc` | 技术文档与协议图谱 | doc.iottiny.top |
| `zen` | 读书 · 思想 · 心智 | zen.iottiny.top |

## 当前内容

- [纳瓦尔宝典 · 卡片版](./naval/) — Naval Ravikant 关于财富、幸福、哲学的判断，21 张卡片
- [遥远的救世主 · 卡片版](./tian-dao/) — 豆豆笔下丁元英谈文化属性、天道、觉者，15 张卡片

## 工程范式

跟 `doc` 一致：零依赖 · self-contained HTML · 浏览器双击即看。每本书一个子目录，子目录里的 `index.html` 自包含全部 CSS / JS。详见 [`AGENTS.md`](./AGENTS.md)。
